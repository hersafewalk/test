Logo artwork is based on your supplied transparent logo file, recoloured to exact palette colours while preserving its transparency and geometry. Ice White logo is used on dark backgrounds; Obsidian logo is used in light mode.

Deploy:
1. Extract this ZIP.
2. Open https://github.com/myshieldlabs/msl-website
3. Replace the existing website files with the contents of this folder (keep the assets folder).
4. Commit to the branch/folder configured for GitHub Pages.
5. Keep your existing custom domain and DNS configuration unchanged.

Before publishing:
- Replace each social placeholder href="#" in index.html with the official LinkedIn, Instagram and YouTube URLs.
- Contact email is set to myshieldlabs@gmail.com.
- Dark mode is the default; the theme toggle switches to light mode and remembers the choice.
